# Скрапер allenbrau.ru

Собирает товары с сайта бренда и складывает в `.xlsx`-файлы — по одному на
категорию — в формате, который уже понимает импорт в админке.

## Установка (один раз)

```
cd scripts/scraper
npm install
npx playwright install chromium
```

## Запуск

```
node scrape.js
```

Откроется окно браузера, и скрипт сам пройдёт по всем 10 категориям сайта
(смесители, ванны, керамика и т.д.), соберёт все товары и запишет файлы в
`scripts/scraper/out/`:

```
out/smesiteli.xlsx
out/vanny.xlsx
out/keramika.xlsx
...
```

Можно запустить только нужные категории:

```
node scrape.js smesiteli vanny
```

(slug'и категорий — это то, что после `/catalog/` в адресе на сайте, напр.
`allenbrau.ru/catalog/smesiteli/` → `smesiteli`.)

Без видимого окна браузера (быстрее, но "смотреть" не получится):

```
node scrape.js --headless
```

## Если прервали на середине

Скрипт сохраняет прогресс после каждого товара в `out/<категория>.json`.
Чтобы продолжить с того же места, а не начинать категорию заново:

```
node scrape.js smesiteli --resume
```

## Что дальше — загрузка в каталог

Каждый `out/<категория>.xlsx` — это заготовка под конкретную категорию
вашего сайта. В админке:

1. Открыть загрузку из Excel.
2. Выбрать **целевую категорию** в вашем каталоге, соответствующую файлу
   (напр. `smesiteli.xlsx` → категория "Смесители").
3. Загрузить файл.

Импортёр сам разберёт колонки: `Номенклатура`, `Артикул`, `Бренд`,
`Коллекция`, `Цвет`, `Характеристики`, `Описание`, `Картинка 1..N`.

## На что обратить внимание

- Один прогон категории "Смесители" (351 товар) занимает около 10–15 минут —
  сайт не резиновый, скрипт намеренно не долбит его запросами без пауз.
- Полный прогон всех 10 категорий может занять несколько часов — можно
  оставить работать в фоне и не смотреть на него постоянно.
- После первого прогона стоит открыть 1–2 файла (например `keramika.xlsx`
  и `mebel-dlya-vannoy.xlsx`) и глазами проверить, что характеристики и
  картинки на месте — вёрстка страниц на сайте местами может отличаться
  для разных типов товаров, и на паре категорий что-то может не вытянуться
  так же чисто, как для смесителей и ванн (на них логика проверена вручную).
- Картинки в файле — это прямые ссылки на allenbrau.ru, а не скачанные
  файлы. Ваш каталог будет их просто показывать по этим ссылкам (как и
  сейчас с URL-адресами картинок), скачивать и перезаливать их не нужно.
